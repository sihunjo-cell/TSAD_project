# GHL 데이터셋 탐색적 데이터 분석(EDA) 보고서

> **분석 대상:** `TSB-AD-M`에 포함된 GHL 다변량 시계열 CSV 25개  
> **분석 목적:** 데이터 구조와 품질을 검증하고, 라벨·이벤트·분포 이동·다변량 및 시간 의존성을 파악하여 이후 이상 탐지 실험의 기준을 마련한다.  
> **중요 전제:** GHL 파일에는 timestamp가 없다. 따라서 본 보고서에서 시간축, 구간 길이, lag는 모두 실제 시간이 아닌 **sample index** 기준이다.

---

## 1. Executive Summary

GHL은 25개의 별도 다변량 시계열 파일로 구성된다. 각 파일에는 19개 입력 특성과 이진 라벨 `Label`이 포함되어 있으며, 전체 관측치는 4,975,025개다. 파일명에 포함된 `tr_n`을 기준으로 앞쪽 1,233,688개 관측치를 학습 prefix로, 나머지 3,741,337개를 평가 구간으로 구분했다. 각 파일은 계산 경계로는 분리하지만, 동일한 GHL 공정 모델과 실험 설계에서 유래하므로 통계적으로 독립적인 iid 표본으로 가정하지 않는다.

전체 이상 포인트는 56,569개로 전체 데이터의 1.137%, 평가 구간의 1.512%다. 연속된 `Label=1`을 하나의 이상 이벤트로 묶으면 총 54개 이벤트가 존재한다. 정상 포인트와 이상 포인트의 비율은 전체 기준 약 86.9:1, 평가 구간 기준 약 65.1:1로 불균형하다.

데이터 품질은 전반적으로 양호하다. 특성 결측값, 무한값, 완전히 중복된 행은 발견되지 않았고 학습 prefix 안에도 양성 라벨이 없다. 다만 10개 파일에서 `C_temperature.T`와 `HT_temperature.T`의 열 순서가 다른 파일과 반대로 배치되어 있다. 열 이름 집합은 동일하므로 이름 기반 로딩에는 문제가 없지만, 고정된 열 위치를 사용하는 NumPy 기반 파이프라인에서는 두 특성이 뒤바뀔 위험이 있다.

EDA에서 가장 중요한 결과는 다음과 같다.

1. 파일명 `1st_n`은 25개 파일 모두 실제 첫 이상 포인트의 **0-based index**와 일치한다.
2. 학습 prefix와 이후 정상 구간 사이에 매우 큰 분포 이동이 존재한다. 특히 `C_level`과 `C_temperature.T`의 파일별 KS 통계량 평균은 0.979다.
3. 이후 정상 구간과 이상 구간을 비교하면 `C_level`, `C_temperature.T`, `dL_rand`, `dT_rand`가 가장 크게 구분된다.
4. 전체 분포 비교와 이벤트 경계 주변의 국소 반응은 서로 다르다. `C_level` 계열은 전체 정상/이상 분포를 강하게 구분하지만, 이벤트 직전 대비 국소 변화의 중앙값은 거의 0이다. 반면 `HT_temperature.T`는 이벤트 국소 변화가 가장 크다.
5. 여러 특성 쌍이 사실상 동일하거나 매우 강하게 결합되어 있다. 특히 `dT_rand`–`dL_rand`, `inj_valve_act`–`boundary.m_flow_in`, `dt_rand`–`limiter1.y`는 학습 표본에서 상관계수 1.0이다.
6. 연속형 특성의 자기상관이 매우 강하다. 일부 특성은 lag 1,000에서도 높은 상관을 유지하므로 행 단위 무작위 분할은 심각한 정보 누출을 만들 수 있다.

## 2. 분석 범위와 방법

### 2.1 분석 단위

각 CSV 파일을 하나의 별도 시계열 경계로 처리했다. 서로 다른 파일의 마지막 행과 첫 행을 연결하지 않았으며, 파일 경계를 넘는 lag나 window도 계산하지 않았다.

여기서 파일을 분리해 처리한다는 것은 계산 경계를 의미하며 통계적 독립성을 뜻하지 않는다. GHL 원논문은 동일한 Modelica gasoil heating loop 모델에서 학습 세트와 여러 fault test set을 생성했다고 설명한다. 따라서 25개 파일은 동일한 생성 시스템과 실험 설계를 공유하는 반복 시계열로 보고, 25개의 iid 표본처럼 해석하지 않는다. 근거: [Filonov et al. (2016), arXiv:1612.06676](https://arxiv.org/abs/1612.06676).

분석 그룹은 다음과 같이 정의했다.

- **학습 prefix (`train_prefix`)**: 파일명의 `tr_n`이 지정하는 앞쪽 n개 행
- **이후 정상 구간 (`post_train_normal`)**: 학습 prefix 이후이면서 `Label=0`인 행
- **이상 구간 (`anomaly`)**: `Label=1`인 행
- **평가 구간 (`post_train_all`)**: 학습 prefix 이후의 모든 행

### 2.2 전체 행을 사용한 분석

다음 항목은 4,975,025개 전체 행을 사용했다.

- 결측값, 무한값, 0의 비율과 기본 통계
- 파일별 행 수와 라벨 분포
- 연속 이상 이벤트의 시작·종료·길이
- 파일 내부 이후 정상/이상 KS 통계량
- 파일·특성별 평균, 표준편차, 분위수와 cardinality
- 학습 prefix 자기상관과 상태 전환율

### 2.3 표본을 사용한 분석

상관관계, PCA, 학습 prefix와 이후 정상 구간의 drift 비교에는 파일·그룹별 최대 3,000개의 결정론적 표본을 사용했다. 난수 seed는 42로 고정했다. 표본 제한은 특정 대용량 파일이 pooled 결과를 지배하는 문제와 계산 비용을 줄이기 위한 것이다.

KS 통계량은 두 경험적 누적분포 사이의 최대 거리를 0~1 범위로 나타낸다. 값이 클수록 분포가 다르다는 뜻이지만, 이상 원인이나 검출 성능을 의미하지 않는다. 강한 자기상관 때문에 독립·동일분포 가정을 만족하지 않으므로 p-value를 추론 근거로 사용하지 않았다.

## 3. 데이터 구성과 sample index

### 3.1 파일명 메타데이터

파일명은 다음 형식을 따른다.

`<번호>_GHL_id_<id>_Sensor_tr_<n>_1st_<m>.csv`

- `id`: 별도 시계열 파일 식별자
- `tr_n`: 학습 prefix의 길이
- `1st_m`: 첫 이상 포인트의 0-based index

예를 들어 `GHL_id_1_Sensor_tr_50000_1st_65001.csv`는 index 0~49,999가 학습 prefix이고, 첫 이상은 index 65,001에서 시작한다. 사람이 행 위치를 1부터 세면 첫 이상 위치는 65,002번째다.

25개 파일 모두 파일명의 `1st_m`과 실제 첫 `Label=1`의 0-based index가 일치했다. 학습 종료 후 첫 이상 전까지의 정상 구간은 최소 100개, 중앙값 42,001개, 최대 106,462개 sample이다. 대부분의 파일에는 학습 종료 후 상당히 긴 정상 평가 구간이 있지만, id 12는 이 간격이 100개뿐이다.

## 4. 스키마와 데이터 품질

### 4.1 스키마 정합성

모든 파일에는 동일한 19개 특성과 `Label`이 존재한다. 그러나 id 3, 7, 11, 13, 17, 18, 22, 23, 24, 25에서는 `C_temperature.T`와 `HT_temperature.T`의 열 순서가 기준 파일과 반대다.

따라서 다음 원칙이 필요하다.

- CSV를 읽은 뒤 기준 열 이름 목록으로 명시적으로 재정렬한다.
- `values[:, 2]`처럼 열 위치만으로 특성을 식별하지 않는다.
- 학습·추론 파이프라인에서 저장된 feature name 순서를 함께 관리한다.

### 4.2 기본 품질 검사

| 검사 항목 | 결과 |
| --- | ---: |
| 특성 결측값 | 0 |
| 특성 무한값 | 0 |
| 완전히 중복된 행 | 0 |
| 학습 prefix의 양성 라벨 | 0 |
| 비정상 라벨 값 | 0 |
| 전체 구간 상수 특성 | 0 |
| 학습 prefix 상수 특성 | 0 |

전체 데이터에서 12개 특성은 고카디널리티, 7개 특성은 이진 특성이다. 학습 prefix만 보면 8개가 고카디널리티, 4개가 중간 카디널리티, 7개가 이진 특성이다. 학습 구간에서는 값의 종류가 제한되지만 이후 구간에서 새로운 값을 갖는 특성이 있다는 뜻이므로, category support와 범위 초과 여부를 별도로 점검할 필요가 있다.

결측값이 없다는 사실은 전처리가 불필요하다는 뜻이 아니다. 특성 스케일, 강한 자기상관, 파일별 baseline 차이, 이진/연속형 혼합은 모델 설계에 직접적인 영향을 준다.

### 5.2 이상 라벨 타임라인

이상 구간은 평가 영역 전체에 균일하게 배치되지 않는다. 각 파일의 첫 이상 위치가 다르고, 일부 파일에서는 짧은 정상 간격을 사이에 둔 여러 이벤트가 군집한다. 따라서 단순한 전체 이상률만으로는 라벨의 시간 구조를 설명할 수 없다.

특히 학습 prefix가 항상 파일 앞부분이고 이상 이벤트는 이후에만 존재하므로, 모델이 이상 패턴 대신 **시계열의 진행 위치**나 장기 drift를 학습할 위험이 있다. `C_level`처럼 시간에 따라 크게 이동하는 특성은 이러한 shortcut을 제공할 수 있다.

### 5.3 이벤트 길이와 간격

## 6. 이후 정상 구간과 이상 구간의 분포 차이

각 파일의 학습 prefix 이후 구간에서 `Label=0` 전체 행과 `Label=1` 전체 행을 비교했다. 파일마다 계산한 KS 통계량을 동일한 가중치로 평균했으므로, 아래 결과는 특정 대용량 파일에 치우친 pooled 결과가 아니라 파일 간 재현성을 반영한 macro 결과다.

## 7. 학습 prefix와 이후 정상 구간의 drift

이상 라벨을 제외하더라도 학습 prefix와 이후 정상 구간의 분포가 동일하지 않다. 파일별 두 그룹에서 각각 최대 3,000개를 표본 추출하여 KS를 계산한 결과는 다음과 같다.

| 순위 | 특성 | 평균 KS | 중앙 KS | 최소 KS | 최대 KS |
| ---: | --- | ---: | ---: | ---: | ---: |
| 1 | `C_level` | 0.979 | 0.979 | 0.964 | 0.999 |
| 2 | `C_temperature.T` | 0.979 | 0.979 | 0.964 | 0.999 |
| 3 | `dL_rand` | 0.357 | 0.345 | 0.199 | 0.561 |
| 4 | `dT_rand` | 0.357 | 0.345 | 0.199 | 0.561 |
| 5 | `limiter.y` | 0.353 | 0.339 | 0.199 | 0.561 |
| 6 | `RT_level_ini` | 0.342 | 0.336 | 0.199 | 0.549 |
| 7 | `RT_level` | 0.251 | 0.241 | 0.121 | 0.404 |
| 8 | `dt_rand` | 0.132 | 0.126 | 0.079 | 0.208 |
| 9 | `limiter1.y` | 0.132 | 0.126 | 0.079 | 0.208 |
| 10 | `RT_temperature.T` | 0.091 | 0.082 | 0.046 | 0.154 |

`C_level`과 `C_temperature.T`의 평균 KS 0.979는 학습 prefix와 이후 정상 구간이 거의 분리되는 수준의 drift를 뜻한다. 최소 KS도 0.964이므로 특정 파일 하나의 문제가 아니라 25개 파일 전반에 걸친 구조다.

이러한 특성은 정상/이상 구분에도 강하지만, 모든 이상이 후반부에 존재한다는 데이터 구조와 결합하면 모델이 실제 이상 패턴 대신 ‘초기인가, 후기인가’를 학습할 수 있다. 따라서 높은 AUROC나 F1을 얻더라도 시간 위치 shortcut 여부를 반드시 검증해야 한다.

권장 민감도 분석은 다음과 같다.

- `C_level`, `C_temperature.T` 포함/제외 결과 비교
- 학습 후 초기 정상 구간과 후기 정상 구간의 false positive 비교
- sample index 또는 장기 추세만 사용하는 단순 baseline과 비교
- 파일별 성능 및 first-anomaly 위치별 성능 비교

### 8.2 PCA 투영

PCA는 학습 prefix 표본에만 scaler와 축을 fit하고, 이후 정상 및 이상 표본을 같은 공간에 투영했다. 19개 특성을 모두 사용할 수 있었으며 PC1은 46.36%, PC2는 14.37%를 설명한다. 두 축의 누적 설명분산은 60.73%다.

시각적으로 학습 prefix와 이후 정상 구간이 PC1 방향으로 크게 이동한다. 이상 표본은 하나의 독립된 군집으로 완전히 분리되기보다 이후 정상 궤적 안의 특정 구간에 놓인다. 이는 단일 전역 경계보다 시간 문맥과 국소 변화가 중요한 데이터임을 시사한다.

PCA는 선형 투영이며 시각화용 표본을 사용했으므로, 군집의 겹침이나 분리를 검출 가능성의 최종 증거로 해석해서는 안 된다.

## 9. 시간 의존성과 상태 지속성

연속형 특성은 매우 강한 자기상관을 보인다. 25개 파일의 학습 prefix에서 계산한 평균 자기상관 중 주요 값은 다음과 같다.

| 특성 | lag 1 | lag 10 | lag 100 | lag 1,000 |
| --- | ---: | ---: | ---: | ---: |
| `C_level` | 1.000 | 1.000 | 0.999 | 0.985 |
| `C_temperature.T` | 1.000 | 1.000 | 0.997 | 0.946 |
| `limiter.y` | 1.000 | 0.999 | 0.985 | 0.847 |
| `dT_rand` | 1.000 | 0.998 | 0.983 | 0.830 |
| `dL_rand` | 1.000 | 0.998 | 0.983 | 0.830 |
| `RT_level_ini` | 1.000에 근접 | 높음 | 0.965 | 0.585 |

이진 상태 특성의 전환율도 낮아 상태가 오랫동안 유지되는 경향이 있다. 반면 `HT_temperature.T`는 인접 학습 행의 거의 모든 구간에서 값이 바뀌지만, 그 변화가 연속적이고 완만해 lag 1 자기상관은 여전히 0.9999 수준이다.

이 구조는 다음과 같은 평가상의 주의를 요구한다.

- 인접 행을 train/validation에 무작위로 나누지 않는다.
- sliding window를 사용한다면 window가 split 경계를 넘지 않도록 한다.
- 여러 겹치는 window를 무작위로 분할하지 않는다.
- point-wise recall뿐 아니라 이벤트 검출 여부와 최초 검출 지연을 함께 평가한다.
- 실제 sampling period가 확인되기 전에는 lag나 이벤트 길이를 초·분으로 환산하지 않는다.

## 10. 모델링 및 평가에 대한 권고사항

### 10.1 데이터 분할

1. 파일별 학습 prefix와 이후 평가 구간을 유지한다.
2. 서로 다른 id를 연결하거나 파일 경계를 넘는 window를 만들지 않는다.
3. 검증용 분할이 필요하면 시간 순서를 보존하고 충분한 gap을 둔다.
4. 겹치는 window가 서로 다른 split에 들어가지 않도록 한다.

### 10.2 전처리

1. 모든 파일을 feature name 기준으로 동일한 순서로 재정렬한다.
2. scaler, PCA, feature selection은 학습 prefix만으로 fit한다.
3. 평가 파일 전체 통계를 사용하는 정규화는 미래 정보 누출 가능성을 검토한다.
4. 이진 특성과 연속형 특성을 구분해 전처리한다.
5. 완전 상관 특성 쌍을 모두 포함한 경우와 대표 특성만 포함한 경우를 비교한다.

### 10.3 shortcut 및 drift 검증

1. `C_level`, `C_temperature.T` 포함/제외 ablation을 수행한다.
2. sample index나 장기 추세만 사용하는 단순 baseline을 추가한다.
3. 평가 정상 구간을 초기·중기·후기로 나누어 false positive 변화를 확인한다.
4. id별 성능과 first-anomaly 위치별 성능을 함께 보고한다.
5. 전체 정상/이상 분포 차이와 이벤트 경계 국소 반응을 구분해 해석한다.

### 10.4 평가 지표

포인트 단위와 이벤트 단위 지표를 함께 사용해야 한다.

- Point-wise precision, recall, F1, PR-AUC
- 파일별 metric과 macro 평균
- 이벤트 검출률
- 최초 검출 지연(sample 단위)
- 이벤트별 false alarm 수
- 정상 시간당 false alarm은 sampling period가 확인된 뒤에만 계산

이벤트가 대부분 약 1,000 samples 길이이므로 point adjustment 방식은 성능을 크게 부풀릴 수 있다. 사용 여부와 허용 범위를 명확히 문서화해야 한다.

## 11. 해석의 한계

- timestamp와 sampling period가 없어 실제 시간 단위 분석을 할 수 없다.
- 파일명과 열 이름 외의 도메인 명세를 사용하지 않았으므로 물리적 의미나 공격 시나리오를 단정하지 않는다.
- `Label=1`과의 분포 연관성은 인과관계나 공격 대상 특성을 의미하지 않는다.
- KS는 강한 자기상관의 영향을 받으므로 독립 표본 검정으로 해석하지 않았다.
- PCA, 상관, 학습/이후 정상 drift는 결정론적 표본에 기반한다.
- 제공된 파일 구조만으로 공식 benchmark의 scoring 및 point-adjustment 규칙을 확정할 수 없다.
- 이벤트 직전·직후 평균 분석은 변화의 방향과 크기를 요약하지만, 복잡한 slope 변화나 지연 반응을 모두 포착하지는 않는다.

---

## 12. 결론

GHL은 결측이나 라벨 오류가 거의 없는 정돈된 데이터지만, 모델링 관점에서는 단순한 데이터가 아니다. 학습 prefix와 이후 정상 구간 사이의 강한 drift, 파일별 baseline 차이, 매우 높은 자기상관, 중복 특성, 파일마다 다른 이벤트 배치는 높은 성능이 실제 이상 탐지 능력인지 시간 위치와 상태 정보를 이용한 shortcut인지 구분하기 어렵게 만든다.

따라서 GHL 실험의 핵심은 복잡한 모델을 선택하는 것보다 다음 원칙을 지키는 데 있다.

- 파일과 시간 경계를 보존한다.
- 학습 prefix만으로 전처리를 fit한다.
- 열 이름 기준 스키마를 강제한다.
- drift가 큰 특성의 민감도 분석을 수행한다.
- micro와 macro, 포인트와 이벤트 지표를 함께 보고한다.
- 전체 분포 연관성과 이벤트 국소 반응을 분리해서 해석한다.

이 원칙을 지키면 GHL의 높은 시간 의존성과 구조적 drift를 모델 성능으로 오인하는 위험을 줄이고, 재현 가능하고 설득력 있는 이상 탐지 실험을 설계할 수 있다.
