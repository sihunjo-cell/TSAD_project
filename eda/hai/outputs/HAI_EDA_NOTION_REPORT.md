> **분석 범위:** 데이터 구조, 시간축, 품질, 라벨 정합성, 분포, 시계열 특성, 변수 관계, 이벤트별 반응

## 1. 핵심 요약

HAI-23.05는 86개 공정 변수를 1초 간격으로 기록한 다변량 시계열 데이터다. 제공된 6개 데이터 파일에는 총 1,180,800개 시점이 있으며, 이 중 학습 데이터는 896,400개, 테스트 데이터는 284,400개다.

파일 수준의 데이터 품질은 전반적으로 양호하다. 모든 데이터 파일에서 특성 결측값, 무한값, 중복 timestamp, 완전 중복 행 및 파일 내부 시간 누락이 발견되지 않았다. 다만 학습 데이터에는 값이 변하지 않는 특성이 20개 존재하므로 모델 입력 구성 단계에서 처리 여부를 검토해야 한다.

테스트 데이터의 이상 포인트는 11,384개로 전체 테스트 시점의 4.003%이며, 연속된 이상 구간 기준으로는 총 52개 이벤트다. `label-test2.csv`는 초 단위 시간 정보가 손실되어 timestamp가 분 단위로 반복되지만, 원본 테스트 데이터의 분 단위 timestamp와 모든 행의 순서가 일치한다. 따라서 본 분석에서는 행 위치를 기준으로 원본 테스트 timestamp를 결합했다. 한편 `summary_label2.txt`의 상세 이벤트 38개는 CSV와 일치하지만, 헤더의 공격 횟수와 총시간은 실제 라벨 집계와 일치하지 않는다.

정상 라벨 구간과 이상 라벨 구간의 차이는 일부 변수에서 관찰되지만, 그 양상은 `hai-test1.csv`와 `hai-test2.csv`에서 동일하지 않다. 또한 학습 데이터와 테스트 정상 라벨 구간 사이의 분포 차이, 파일별 평균 이동, 강한 자기상관이 함께 확인되었다. 따라서 이후 모델 실험에서는 데이터 양의 효과와 수집 시기·파일별 수준 및 주기 차이를 혼동하지 않도록 주의해야 한다.

## 2. 분석 목적과 범위

이번 EDA의 목적은 다음과 같다.

1. 데이터 파일의 구조와 시간적 범위를 파악한다.
2. 결측값, 무한값, 중복, 시간 누락과 같은 기본 품질 문제를 점검한다.
3. 테스트 라벨의 정렬 상태와 이상 이벤트 구성을 검증한다.
4. 정상 라벨 구간과 이상 라벨 구간에서 차이가 크게 나타나는 특성을 탐색한다.
5. 학습 데이터와 테스트 데이터 사이의 분포 이동 가능성을 확인한다.
6. 상관관계, PCA, 자기상관 및 이벤트별 반응을 통해 데이터의 다변량·시계열 구조를 이해한다.

이번 단계에서는 학습 데이터를 5~100%로 나누거나 모델을 학습하지 않았다. 데이터 크기별 모델 성능 비교는 EDA 이후의 독립된 실험 단계로 남겨 두었다.

### 보고서에서 사용하는 용어

- **시점 또는 관측치:** 1초마다 기록된 한 행이다.
- **특성(feature):** 모델 입력 후보가 되는 86개 변수다.
- **학습 데이터(라벨 미제공):** `hai-train*.csv`를 의미한다. 정상이라고 검증된 라벨이 없으므로 본 보고서에서는 이를 정상 데이터라고 부르지 않는다.
- **테스트 정상 라벨 구간:** 테스트 파일에서 `label=0`인 구간이다. 이는 평가 라벨상의 정상 구간이며 물리적 안전 상태가 별도로 검증되었다는 뜻은 아니다.
- **이상 포인트:** 특정 1초에 부여된 `label=1` 한 개를 의미한다.
- **이상 이벤트:** `label=1`이 끊기지 않고 연속된 하나의 구간이다.
- **KS 통계량:** 두 경험적 분포 사이의 최대 누적 차이를 나타내는 0~1 지표다. 정확도, 이상 확률, 인과관계 또는 모델 중요도를 의미하지 않는다.
- **분포 이동(drift):** 시기나 파일 사이에서 관측되는 분포 차이다. 그 자체로 공격이나 고장을 뜻하지 않는다.
- **접두어(prefix):** `P1`, `P2`, `P3`, `P4`, `x100*`와 같은 열 이름의 그룹 표기다. 논문 확인 전에는 물리적 서브시스템 의미를 부여하지 않는다.

> 권장 캡션: 파란색은 라벨 미제공 학습 파일, 주황색은 테스트 파일이다. 각 막대는 파일이 실제로 포함하는 시간 범위를 나타낸다. 파일 내부는 1초 간격으로 연속적이지만, 일부 파일 경계에는 관측되지 않은 시간이 존재한다.

### 3.2 시간 연속성

각 파일 내부의 timestamp는 모두 단조 증가하며, 인접 timestamp 차이는 정확히 1초다. 파일끼리 시간 범위가 겹치는 경우도 없다.

다만 전체 파일을 시간순으로 배열하면 다음의 미관측 구간이 존재한다.

- `hai-train1.csv` 종료 후 `hai-test1.csv` 시작 전: 112시간
- `hai-train2.csv` 종료 후 `hai-test2.csv` 시작 전: 8시간
- `hai-train3.csv` 종료 후 `hai-train4.csv` 시작 전: 38시간

반대로 `hai-test1.csv`와 `hai-train2.csv`, `hai-test2.csv`와 `hai-train3.csv`의 경계는 1초 차이로 연속된다.

파일의 실제 시간 순서는 `train1 → test1 → train2 → test2 → train3 → train4`다. 즉 제공된 train/test 명칭은 단순한 과거 학습·미래 평가 분할이 아니며, 전체 학습 파일을 사용하면 test1이나 test2보다 나중에 수집된 학습 데이터도 포함된다. 논문의 공식 평가 프로토콜을 확인하기 전에는 이를 임의로 미래 예측 구조라고 설명하지 않는다.

이 구조는 후속 시계열 모델링에서 중요하다. 하나의 window가 서로 다른 파일이나 미관측 구간을 가로질러 생성되면 실제로 존재하지 않는 시간적 연결을 학습하게 되므로, window는 파일 경계 안에서 구성해야 한다.

### 4.2 값의 다양성과 상수 특성

전체 기간의 고유값 수(cardinality)를 기준으로 분류하면 고유값 201개 이상인 고유값 수가 높은 특성 55개, 상수 18개, 이진형 8개, 고유값 21~200개의 중간형 4개, 고유값 3~20개의 낮은형 1개다.

전체 데이터에서 값이 변하지 않는 18개 특성은 다음과 같다.

`P1_PIT01_HH`, `P1_PP01AD`, `P1_PP01AR`, `P1_PP01BD`, `P1_PP01BR`, `P1_PP02D`, `P1_PP02R`, `P1_SOL01D`, `P1_SOL03D`, `P1_STSP`, `P2_RTR`, `P2_TripEx`, `P2_VTR01`, `P2_VTR02`, `P2_VTR03`, `P2_VTR04`, `P3_LH01`, `P3_LL01`

이 18개 특성은 현재 데이터 범위 안에서 변별 정보를 제공하지 않는다. 학습 데이터만 기준으로 하면 상수 특성은 20개이며, 추가되는 두 특성은 `P2_Emerg`와 `P2_OnOff`다.

- `P2_Emerg`: 학습 데이터와 테스트 정상 라벨 구간에서는 0으로 고정되어 있지만, 테스트 이상 라벨 구간의 94개 시점에서 1이 관측된다.
- `P2_OnOff`: 학습 데이터와 테스트 정상 라벨 구간에서는 1로 고정되어 있지만, 테스트 이상 라벨 구간의 115개 시점에서 0이 관측된다.

두 변수는 학습에서 한 번도 관측하지 못한 범위 밖(out-of-support) 상태 신호이며, 0분산 전처리 이슈나 모델의 지름길(shortcut) 단서가 될 가능성이 있다. 그러나 이것만으로 라벨 누수라고 단정할 수는 없다. 후속 모델 실험에서는 두 변수를 포함한 결과와 제외한 결과를 함께 비교하는 민감도 분석이 유용하다.

## 5. 테스트 라벨 검증과 이상 이벤트 구성

### 5.1 라벨 분포

| 테스트 파일 | 전체 시점 | 이상 포인트 | 이상 비율 | 연속 이상 이벤트 |
| --- | ---: | ---: | ---: | ---: |
| `hai-test1.csv` | 54,000 | 2,981 | 5.520% | 14 |
| `hai-test2.csv` | 230,400 | 8,403 | 3.647% | 38 |
| **전체** | **284,400** | **11,384** | **4.003%** | **52** |

정상 라벨 포인트는 273,016개이며 정상과 이상의 비율은 약 23.98:1이다.

이상 포인트와 이상 이벤트는 서로 다른 단위다. 예를 들어 하나의 이상 이벤트가 100초 동안 이어지면 이상 포인트는 약 100개지만 이벤트는 1개다. 따라서 후속 평가에서도 포인트 단위 성능과 이벤트 단위 성능을 구분해야 한다.

> 📊 **시각화 삽입 — 이상 라벨 타임라인**  
> 사용 파일: `03_label_timeline.png`  
> 권장 캡션: 빨간 구간은 연속된 이상 라벨을 나타낸다. test1에는 14개, test2에는 38개의 이상 이벤트가 있으며 이벤트의 간격과 길이가 균일하지 않다.

시각적으로도 이상 이벤트는 테스트 전 구간에 일정한 간격으로 배치되지 않는다. `hai-test2.csv`에는 여러 짧은 이벤트와 일부 긴 이벤트가 혼재하며, 중간에 비교적 긴 정상 라벨 구간도 존재한다. 전체 비율만으로는 이러한 시간적 구조를 표현할 수 없다.

### 5.2 `label-test2.csv` 시간 정보 이슈

`label-test1.csv`의 timestamp는 초 단위 원본 테스트 timestamp와 정확히 일치한다. 반면 `label-test2.csv`는 초 정보가 제거되어 230,400개 행에 3,841개의 고유한 분 단위 timestamp만 존재한다.

원본 `hai-test2.csv`의 timestamp를 분 단위로 내림한 값과 라벨 파일의 timestamp를 행별로 비교한 결과, 230,400개 행이 모두 같은 순서로 일치했다. 이에 따라 본 EDA에서는 라벨 행의 순서를 유지한 채 원본 테스트 데이터의 초 단위 timestamp를 결합하는 positional alignment를 적용했다.

> ⚠️ **라벨 사용 시 주의**  
> `label-test2.csv`의 timestamp만으로 join하면 분 단위 중복 key 때문에 many-to-many 행 증식이 발생할 수 있고, 초 단위로는 일대일 결합할 수 없다. 반드시 검증된 행 순서를 기준으로 `hai-test2.csv`의 원본 초 단위 timestamp를 결합해야 한다.

### 5.3 요약 파일과 실제 라벨의 불일치

`summary_label2.txt`의 상세 이벤트 표에 기록된 38개 이벤트의 시작·종료 시각은 실제 CSV 라벨과 모두 일치한다. 그러나 요약 파일 헤더는 공격 횟수를 40회, 총 span을 `02:25:35`로 표기하고 있다.

실제 연속 라벨 기준 결과는 다음과 같다.

- 연속 이벤트 수: 38개
- 각 이벤트의 `종료 시각 - 시작 시각` 합: `02:19:25`
- 이상 포인트 수: 1초 주기의 양성 시점 8,403개

따라서 클래스 비율과 모델 평가에는 CSV의 포인트 라벨을 기준으로 사용한다. 요약 파일의 헤더 집계는 참고값으로 사용하지 않는다.

### 5.4 이벤트 길이와 이벤트 간 간격

52개 이벤트의 시작과 종료 사이 span은 최소 55초, 중앙값 132초, 최대 2,051초다. 시작과 종료 시점을 모두 포함한 포인트 수는 span보다 1개 많다.

## 7. 이벤트별 반응의 이질성

전체 정상·이상 분포 비교는 이벤트 사이의 차이를 평균으로 가릴 수 있다. 이를 확인하기 위해 각 이벤트의 특성 평균을 해당 테스트 파일의 정상 라벨 평균과 비교하고, 정상 라벨 표준편차 단위로 표현했다.

> 📊 **시각화 삽입 — 이벤트별 주요 특성 평균 변화 히트맵**  
> 사용 파일: `10_event_feature_heatmap.png`  
> 권장 캡션: 열은 52개 이상 이벤트, 행은 정상·이상 분포 차이가 큰 특성이다. 붉은색과 푸른색은 각각 정상 라벨 기준보다 높은 방향과 낮은 방향의 평균 이동을 나타내며, 표시 범위는 ±10 SD로 제한했다.

히트맵에서 동일한 특성도 이벤트에 따라 이동 방향과 크기가 달라진다. 일부 이벤트는 여러 특성이 함께 움직이지만, 다른 이벤트에서는 변화가 제한적이다. 이는 단일 전역 임계값의 한계를 시사하지만, 변수 조합과 시간 구조의 유용성은 후속 모델 실험에서 별도로 검증해야 한다. 공격 유형이나 공정 상태 정보가 없으므로 이벤트별 차이의 원인은 현재 데이터만으로 식별할 수 없다.

### 7.1 탐색적 반응 지연과 복귀 시간

반응 지연은 다음의 명시적 규칙으로 계산했다.

1. 각 이벤트 직전 300초의 정상 라벨 구간 중앙값을 이벤트 직전 기준값으로 사용한다.

## 9. 변수 간 관계와 차원 구조

### 9.1 학습 데이터의 상관관계

학습 데이터에서 값이 변하지 않는 20개 특성을 제외한 66개 특성으로 Pearson 상관관계를 계산했다. 결정적 표본에서 절대 상관계수 `|r| ≥ 0.95`인 특성 쌍은 40개였다.

> 📊 **시각화 삽입 — 학습 데이터 특성 상관행렬**  
> 사용 파일: `07_train_sample_correlation.png`  
> 권장 캡션: 학습 상수 특성 20개를 제외한 66개 특성의 결정적 표본 상관행렬이다. 붉은색은 양의 상관, 푸른색은 음의 상관을 나타낸다. 일부 특성 군집은 매우 강하게 함께 움직이며, 상관관계는 인과관계를 의미하지 않는다.

강한 상관은 동일한 공정 상태를 여러 변수가 중복해서 표현할 가능성을 보여준다. 단순 모델에서는 다중공선성이 계수 안정성에 영향을 줄 수 있고, 복잡한 모델에서는 중복 특성이 불필요한 복잡도를 만들 수 있다. 반대로 시계열 이상 탐지에서는 평소 강하게 유지되던 관계가 깨지는 현상 자체가 유용한 신호가 될 수 있다.

- PC1 설명분산: 13.52%
- PC2 설명분산: 12.62%
- 두 축의 누적 설명분산: 26.14%

> 📊 **시각화 삽입 — 학습·테스트 데이터 PCA 투영**  
> 사용 파일: `08_pca_projection.png`  
> 권장 캡션: 테스트 이상 포인트 중 일부는 학습 및 테스트 정상 라벨 영역 밖으로 확장되지만, 많은 점이 정상 영역과 겹친다. PC1과 PC2는 전체 분산의 26.14%만 설명한다.

> 📊 **시각화 삽입 — 정상·이상 라벨 구간의 상관구조 변화**

> 📊 **시각화 삽입 — 시차별 자기상관**  
> 사용 파일: `11_autocorrelation.png`  
> 권장 캡션: 4개 학습 파일에서 계산한 자기상관의 평균이며, 평균 절대 자기상관이 강한 상위 특성을 표시했다. 1 Hz 데이터이므로 시차(lag) 1·10·60·300 sample은 각각 1·10·60·300초다. 붉은색은 양의, 푸른색은 음의 자기상관이며 절댓값이 1에 가까울수록 시간 의존성이 강하다.

## 12. 종합 해석

### 12.1 데이터 자체의 기술적 품질은 양호하다

결측값, 무한값, 중복 행, timestamp 중복 및 파일 내부 시간 누락이 없다. 따라서 기본적인 데이터 손상보다는 상수 특성, 스케일 차이, 시간 의존성, 파일 간 분포 차이가 주요 전처리 이슈다.

### 12.2 라벨은 사용할 수 있지만 test2의 결합 규칙을 고정해야 한다

test2 라벨은 초 단위 timestamp join이 불가능하다. 검증된 행 순서를 이용해 원본 테스트 timestamp를 결합해야 하며, 이 규칙을 모든 후속 실험 코드에서 동일하게 적용해야 한다. `summary_label2.txt` 헤더 대신 CSV 포인트 라벨을 평가 기준으로 사용한다.

### 12.3 이상은 하나의 단순한 패턴으로 표현되지 않는다

test1과 test2의 상위 분포 변화 특성이 다르고, 이벤트별 평균 이동의 방향과 크기도 다르다. PCA에서도 많은 이상 포인트가 정상 라벨 영역과 겹친다. 따라서 하나의 전역 임계값이나 소수 특성이 모든 이벤트에 동일하게 유효하다고 가정하기 어려우며, 이는 후속 모델 실험에서 검증해야 한다.

### 12.4 파일·시간 효과가 이상 효과와 함께 존재한다

학습 데이터와 테스트 정상 라벨 구간 사이에 분포 이동이 있으며 파일별 평균 수준도 다르다. 주요 시계열에는 반복 주기와 파일별 수준·주기 변화가 관찰되며, 운전 조건 차이가 원인일 가능성이 있다. 모델은 공격 특성 대신 파일 또는 시간대의 특징을 학습할 수 있으므로 파일별 성능과 시간 순서를 함께 확인해야 한다.

### 12.5 강한 시계열 의존성이 존재한다

여러 특성이 높은 자기상관을 보이며 상관성이 매우 높은 특성 쌍도 다수 존재한다. 행 단위 무작위 분할은 성능을 낙관적으로 만들 수 있으며, 단순 모델과 딥러닝 모델 모두 같은 시간·파일 경계 원칙으로 비교해야 한다.

## 13. 후속 데이터 크기별 모델 실험에 전달할 관찰사항

이번 EDA는 학습 데이터의 5~100% 부분집합이나 모델을 구성하지 않았다. 아래 내용은 EDA 결론을 바꾸기 위한 조건이 아니라, 다음 단계에서 데이터 양의 효과를 공정하게 비교하기 위해 통제할 후보들이다.

가장 먼저 논문의 공식 train/test 프로토콜을 확인하고, 공식 학습 범위 안에서만 5~100% 부분집합을 구성해야 한다. 제공 파일의 시간순서만을 근거로 임의의 학습 범위를 정하지 않는다.

1. **시간 순서와 파일 경계 보존**  
   무작위 행 분할은 인접한 1초 시점의 높은 유사성 때문에 성능을 과대평가할 수 있다. 부분집합 및 검증 구간의 구성 원칙은 후속 단계에서 시간축 기준으로 고정해야 한다.

2. **중첩된 학습 부분집합**  
   가능하면 5% 데이터가 10% 데이터에 포함되고, 10%가 더 큰 부분집합에 포함되는 형태로 구성하면 데이터 크기 증가 효과를 더 직접적으로 비교할 수 있다. 다만 단일 연속 구간만 늘리면 특정 시기나 운전 조건의 추가 효과가 데이터 양 효과로 보일 수 있다. 동일 비율을 여러 시간 블록 또는 seed로 반복하고 평균뿐 아니라 표준편차나 신뢰구간도 기록하는 방안을 검토한다.

3. **동일한 검증·테스트 조건**  
   모델 구조나 학습 비율이 달라도 최종 test1·test2와 평가 규칙은 동일하게 유지해야 한다. 통합 지표뿐 아니라 테스트 파일별 지표를 함께 기록한다.

4. **학습 데이터만 사용하는 전처리**  
   스케일 조정 규칙, 결측 대체 규칙, 특성 선택 및 임계값은 각 학습 비율의 데이터에서만 추정한다. 테스트 정상 라벨 구간의 통계를 학습 과정에 사용하지 않는다. 특히 6절과 7절의 테스트 라벨 기반 순위 및 이벤트 분석은 사후 기술용이며, 같은 테스트 평가의 특성 선택이나 하이퍼파라미터 결정에 사용하지 않는다.

5. **상수 및 shortcut 후보의 처리 기록**  
   전체 상수 18개는 제거 후보이며, `P2_Emerg`와 `P2_OnOff`는 포함·제외 결과를 비교할 가치가 있다. 모든 모델에서 동일한 feature set 정책을 적용한다.

6. **포인트와 이벤트 평가의 분리**  
   이상 포인트가 4.003%이므로 accuracy만으로 성능을 판단하기 어렵다. point-level precision, recall, F1, PR-AUC와 함께 이벤트 탐지율, 탐지 지연, false alarm 구간을 분리해 볼 필요가 있다.

7. **시계열 window 생성 규칙 통일**  
   window가 파일 경계나 미관측 시간 구간을 가로지르지 않도록 하며, 모델 간 비교에서는 입력 시간 길이와 stride 차이가 결과에 미치는 영향을 기록한다.

EDA는 성능과 학습 데이터 크기의 관계에 답한 단계가 아니다. 대신 공정한 learning curve 비교를 위해 통제해야 할 데이터 위험요인을 식별했다.

## 14. 해석의 한계

- 본 분석은 제공 파일만을 사용했으며 논문의 공정 설명, 공격 유형, 대상 변수 및 운전 시나리오를 결합하지 않았다.
- 학습 파일에는 라벨이 없으므로 학습 데이터 전체가 정상이라고 검증할 수 없다.
- train/test 파일은 시간순으로 완전히 분리되어 있지 않으므로, 공식 프로토콜 확인 전에는 전체 train을 과거 데이터라고 가정할 수 없다.
- 정상·이상 KS와 기본 통계량은 전체 행으로 계산했다. 학습·테스트 분포 이동의 KS, 분위수, 상관관계 및 PCA는 계산 효율을 위해 고정 seed의 재현 가능한 표본을 사용했으며, 분포 이동 표의 평균·표준편차와 표준화 평균 차이는 전체 행으로 계산했다.
- 시계열 데이터의 강한 자기상관과 이산 특성 때문에 iid·연속 분포를 가정하는 통계적 유의성 해석은 적용하지 않았다.
- 이벤트 반응과 복귀 시간은 명시한 임계값에 따른 탐색적 지표다. 라벨 경계가 물리적 반응 경계라는 보장은 없다.
- 상관관계, 분포 차이, PCA 위치 차이는 인과관계를 의미하지 않는다.
- 일부 상관 변화는 한 테스트 파일에서만 계산 가능하므로 전체 데이터의 공통 현상으로 일반화할 수 없다.

## 15. 결론

HAI-23.05는 파일 내부 시간축과 기본 품질 문제가 적은 1초 주기 다변량 시계열 데이터다. 그러나 모델링 관점에서는 다음 네 가지가 핵심이다.

1. test2 라벨은 검증된 행 순서로 정렬해야 한다.
2. 이상 포인트는 4.003%로 불균형하며 52개의 길이가 다른 이벤트로 구성된다.
3. 정상·이상 차이는 이벤트와 테스트 파일에 따라 이질적이며, 파일 간 분포 이동과 수준·주기 차이도 함께 존재한다.
4. 강한 자기상관과 상관 특성 때문에 시간 순서와 파일 경계를 무시한 분할은 피해야 한다.

따라서 이후의 단순 모델부터 딥러닝 모델까지의 비교에서는 동일한 데이터 경계, 동일한 전처리 원칙, 파일별·이벤트별 평가를 유지해야 한다. 논문 검토 후 변수의 물리적 의미와 공격 시나리오를 본 결과에 연결하면, 현재의 통계적 관찰을 공정 관점에서 더 구체적으로 해석할 수 있다.
