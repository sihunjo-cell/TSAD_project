# A(강혁) — 데이터·Manifest

전체 파이프라인의 첫 마디입니다. 근거는 계획서 4절·14나와 D-17, D-19이고, 강혁님 산출물이 나와야 exp01b(EDA)가 출발합니다.

## 1부. 제가 당장 필요한 것 (필수 — 이게 와야 다음 단계가 열립니다)

GHL부터 부탁드립니다. TSB-AD-M zip에서 시계열 25개를 꺼내고, 시계열마다 파일명·행 수·열 수·학습/테스트 경계 인덱스를 표로 정리해 주세요. 계획서 기준으로 학습 구간이 39,938~50,000 범위인데, 여기서 벗어나는 시계열이 있으면 따로 표시해 주시면 됩니다.

HAI는 함정이 하나 있습니다. git-lfs 저장소라 clone만 하면 실제 데이터 대신 포인터 파일이 내려오니, git lfs pull까지 하고 나서 각 CSV의 첫 줄을 열어 포인터 파일이 아닌지 확인한 뒤 행·열 수 표를 만들어 주세요. HAI 버전과 "시계열 하나"를 무엇으로 셀지도 이때 결정해서 문서에 남겨 주셔야 합니다 — 이 결정이 채널 수 N을 확정하고, N이 정해져야 configs/gdn_hyperparams.yaml의 HAI topk 자리(지금은 "Manifest 확정 후"로 비워져 있습니다, D-17)가 채워집니다. k는 max(5, ⌈0.25N⌉) 규칙이라 59~86ch면 15~22가 나옵니다.

기입 위치는 제 저장소의 docs/manifest_draft.md(신규)입니다. 표 2개와 버전 결정을 넣어 주세요. 데이터 실물은 저장소 밖 공유 경로에 두고 경로만 적습니다. 이 커밋이 곧 완료 신호입니다.

iTrust 발송 계획서 14나에 적힌 그대로 진행하시면 됩니다.

## 2부. 이후에 하면 좋은 것 (부차 — 세밀할수록 결정이 빨리 잠깁니다)

1부가 끝난 뒤의 EDA 보강입니다. 원칙 하나만 공유하면, 세밀하게 판다는 건 그림을 많이 그리는 게 아니라 **지금 비워둔 결정 자리를 채우는 근거를 만드는 것**입니다. 그래서 아래 표마다 "이 표가 채우는 결정"이 붙어 있습니다 — 표를 만들 때 그 번호를 헤더에 같이 적어 주세요.

### ① 길이·경계 → T 정의(E1·E4)와 학습 길이 하한

- 시계열별 총 길이, 학습/테스트 경계, 채널별 결측 위치·비율.
- 학습 구간 앞부분의 채널별 이동 평균·분산 그래프로 **안정화가 끝나는 시점**을 시계열마다 추정. 다른 설비의 "앞 2160포인트 제거" 관행은 그대로 못 쓰니(계획서 4절), 우리 데이터 근거의 절단점 제안이 필요합니다.
- **5% 조건 시뮬레이션**: 시계열마다 ceil(0.05T)가 몇 포인트인지, 거기서 validation 10%와 윈도 길이를 빼면 학습 윈도가 몇 개 남는지. 예시 하한으로 돌려봤을 때 5%뿐 아니라 10% 조건도 미달한 전례가 있어서, 하한 논의는 이 표가 있어야 숫자로 됩니다.

### ② 채널 → N·k(D-17)와 정규화 위험 채널(D-07)

- HAI 버전별 채널 수와, "시계열 하나" 단위 후보별로 N이 얼마가 되는지 + 각 N의 k 값 병기.
- 채널별 기초 통계에서 **상수·준상수 채널(σ≈0)** 골라내기 — median-IQR 정규화에서 IQR=0 채널은 epsilon에만 의존하게 되는 걸 이미 확인했습니다.
- 채널별 결측비율·이상치 라벨링 비율(계획서 14나에 적힌 강혁님 관심사 그대로).

### ③ 라벨 → ℓ 배제 근거(7-6)·다운샘플·오염 확인

- 시계열별 이상 구간 개수와 길이 분포(중앙값·최소·최대). 세 군데에 쓰입니다: 7-6에서 후보 ②를 "알고 배제했다"고 쓰려면 이 값이 실제로 있어야 하고, 다운샘플 배율이 가장 짧은 구간을 삼키는지 판정할 수 있고, 라벨 합치기 방식과 ℓ의 상호작용도 여기서 보입니다.
- 학습 구간 라벨 오염 여부 — GECCO의 1.44% 같은 케이스가 GHL·HAI에도 있는지.

### ④ 주기성 → ℓ_max 원료(7-6 후보 ①)

- 채널별 자기상관 국소 최대를 시계열×채널 표(또는 히트맵)로. 계산 채택은 지우님 몫이지만, lag 상한 제안은 데이터를 본 사람이 해야 합니다.
- 다운샘플 배율 후보별로 주기가 어떻게 변하는지까지 있으면 배율과 ℓ이 한 표에서 정리됩니다.

### 경계선과 형식

- **테스트 구간과 라벨은 열어보되, 모델·분할·정규화 결정의 근거로는 학습 구간 통계만 씁니다.** 라벨 통계는 채점기·난이도 쪽 재료로만 갑니다. 이 한 줄을 EDA 문서 맨 위에 적어 두면 "결과 보고 정한 것 아니냐"는 반문이 원천 차단됩니다.
- 형식은 전부 "시계열 × 항목" 표로, docs/manifest_draft.md 확장 또는 exp01b 폴더에. 그림은 안정화 구간·주기 정도면 충분합니다.
