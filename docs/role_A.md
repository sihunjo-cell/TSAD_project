# A(강혁) — 데이터·Manifest

전체 파이프라인의 첫 마디입니다. 근거는 계획서 4절·14나와 D-17, D-19이고, 강혁님 산출물이 나와야 exp01b(EDA)가 출발합니다.

GHL부터 부탁드립니다. TSB-AD-M zip에서 시계열 25개를 꺼내고, 시계열마다 파일명·행 수·열 수·학습/테스트 경계 인덱스를 표로 정리해 주세요. 계획서 기준으로 학습 구간이 39,938~50,000 범위인데, 여기서 벗어나는 시계열이 있으면 따로 표시해 주시면 됩니다.

HAI는 함정이 하나 있습니다. git-lfs 저장소라 clone만 하면 실제 데이터 대신 포인터 파일이 내려오니, git lfs pull까지 하고 나서 각 CSV의 첫 줄을 열어 포인터 파일이 아닌지 확인한 뒤 행·열 수 표를 만들어 주세요. HAI 버전과 "시계열 하나"를 무엇으로 셀지도 이때 결정해서 문서에 남겨 주셔야 합니다 — 이 결정이 채널 수 N을 확정하고, N이 정해져야 configs/gdn_hyperparams.yaml의 HAI topk 자리(지금은 "Manifest 확정 후"로 비워져 있습니다, D-17)가 채워집니다. k는 max(5, ⌈0.25N⌉) 규칙이라 59~86ch면 15~22가 나옵니다.

기입 위치는 제 저장소의 docs/manifest_draft.md(신규)입니다. 표 2개와 버전 결정을 넣어 주세요. 데이터 실물은 저장소 밖 공유 경로에 두고 경로만 적습니다. 이 커밋이 곧 완료 신호입니다.

iTrust 발송은 계획서 14나에 적힌 그대로 진행하시면 됩니다.
