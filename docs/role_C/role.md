# C(주혜) — 난이도·통계·집필

주혜님은 결과가 오기 전에 난이도와 통계 규칙을 고정합니다. 저에게서 세 계층의 점수,
metadata, 실행 로그와 HAI edge 집합을 받고 지우에게서 채점 원표를 받습니다.

## 먼저 만들 것

Bonferroni family 범위와 보정값은 결과를 보기 전에 확정합니다. 비율 7개를 한 비교 family로
보면 `α*=0.05/7`, 두 대표 비교를 한 family로 묶으면 `α*=0.05/14`입니다. TOST는 `±δ`
단측 검정 두 번으로 구현합니다. 지속 초과 판정기는
`D=(+,−,+,+,+,+,+)`에서 `c*=20%`를 반환해야 합니다. 전 비율이
양수면 5%를 관측 하한으로 표시하고 교차점이 없을 때도 별도 상태로 보존합니다. bootstrap은
10,000회입니다.

HAI 그래프는 seed 10개가 만드는 45쌍의 Jaccard를 모두 계산해 중앙값, 사분위와 범위로
요약합니다. self-edge를 제거한 edge 집합만 비교합니다.

난이도 분할은 학습 통계와 테스트 원시값으로 계산합니다. 윈도 길이, 채널 max 뒤 윈도 평균,
구간별 최댓값 순서를 실험 전에 고정하고 모델 점수를 본 뒤 기준선을 바꾸지 않습니다. 점수가
도착하면 같은 코드로 `구간 × 모델 × 비율` hit 원표를 만듭니다.

## 점수가 도착한 뒤 할 것

δ는 계층 1의 결정적 방법들이 시계열마다 보이는 산포로 고정합니다. GDN과 PCA,
GDN과 MOMENT_ZS의 차이는 같은 시계열에서 계산하며 GDN은 seed 3회의 중앙값을 씁니다.

교차점 분포 표에는 중앙값, 사분위와 교차점이 없는 비율을 함께 적습니다. 교차점이 없다는
상태를 큰 수로 바꿔 평균 내지 않습니다. 같은 원표로 세 계층 곡선, 난이도별 회수율과 실행
비용 표를 만듭니다.

Wilcoxon, TOST와 bootstrap 결과는 GHL 25개 시계열 안에서만 해석합니다. 같은 시뮬레이터에서
나온 시계열이 독립 모집단 표본이라는 보장이 없으므로 제조 공정 전체로 일반화하지 않습니다.

완료 신호는 난이도 분할과 hit 판정기, 통계 도구와 Jaccard 집계기의 테스트 통과입니다.
