# B(지우) — 채점기·계층1/3

제 쪽과의 인터페이스는 파일명 규약과 길이 명세, 딱 두 개입니다. 근거는 계획서 3-4·7-3·7-6·11절과 D-15·D-16, CLAUDE.md 파일명 규약입니다.

파서가 받을 파일명 규약은 {dataset}__{series:02d}__{model}__{tier}__r{ratio:03d}__s{seed}__{raw|smoothed}__{trainnorm|testnorm}(__channels).npy 입니다. seed만 패딩이 없습니다(s1, s10). 실물 예를 하나 들면 GHL__03__GDN__t2__r010__s1__raw__trainnorm.npy 입니다. naming.py는 순수 stdlib라 그대로 복사해 쓰셔도 되고, 환경 이원화와도 충돌하지 않습니다. 채점 대상은 __channels가 붙지 않은 집계본입니다. trainnorm이 본 결과표에 들어가고 testnorm은 부록의 별도 열, __channels는 회수 분석용이라 채점에서 뺍니다.

라벨 정렬이 두 번째 명세입니다. GDN 점수는 길이가 L−W−1이고 라벨은 labels[window_size:-1]로 맞춥니다 — 자세한 내용은 제 docs/score_interface.md를 받은 뒤 채점기에 반영해 주세요. 지우님이 직접 만드는 계층1·3 점수도 같은 규약의 파일명으로 저장해야 결과표가 파서 하나로 닫힙니다.

채점기는 VUS-PR이 주지표이고, (ℓ_max, threshold 격자 250) 쌍을 봉인합니다. TSB-AD의 기본 주기 추정은 첫 채널만 보고 125로 캡을 씌우는 구현이라 쓰면 안 됩니다 — 7-6의 후보 ①로 ℓ을 계산하고, ②를 탈락시킨 사유는 사전 등록용으로 문장으로 남겨 주세요. 무작위 벡터 음성 대조와, PA를 적용하면 무작위가 SOTA를 이기는 역전 재현도 채점기 검증에 포함됩니다.

계층1 wrapper는 KNN/IForest/MP/PCA가 테스트에 fit하는 기본 구현을 학습셋 fit으로 고쳐 쓰고(7-3), PCA 주성분은 GHL=10, HAI=30으로 고정합니다.

채점 규칙의 세부는 실험이 도는 동안 비공개입니다(11절). 제 쪽에는 파서 호환 여부만 회신해 주시면 됩니다.

(참고: 위에서 "받은 뒤"라고 한 docs/score_interface.md는 현재 작성이 끝나 있습니다. 그 문서가 인터페이스의 최신 원본입니다.)
