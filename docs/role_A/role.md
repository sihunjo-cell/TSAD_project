# A(강혁) — 데이터·Manifest

강혁님은 GHL·HAI 데이터 검수와 Manifest 승인을 맡습니다. 제가 모델을 준비하는 데 필요한 실물
표와 최소 EDA는 먼저 만들었습니다. 현재 값이 맞는지 확인하고 주기성 판단을 보완해 주세요.

## 먼저 확인할 내용

`manifest.md`에는 GHL 25개의 파일명, 행·열 수, 학습/테스트 경계를 정리했습니다. 학습 길이는
39,938~50,000이며 범위를 벗어난 시계열은 없습니다.

HAI 23.05는 LFS 포인터가 아닌 CSV 실물로 확인했습니다. CSV 한 파일을 연속 세션 하나로
보고 모델 입력은 86채널로 정했습니다. GDN 이웃 수 22는 재현 기준 회의 전 잠정값입니다.
표와 세션 해석이 맞는지 검토해 주세요.

수정 대상은 `manifest.md`입니다. 검수 결과와 최종 판단만 적고 조사 과정은 남기지 않습니다.
MOMENT·Chronos 가중치는 파일명, 버전, 크기와 SHA-256을 확인한 뒤 저에게 넘깁니다.
iTrust 발송과 일정 확인도 강혁님이 맡습니다.

## 남은 분석

### 길이·채널·라벨

시계열별 총 길이와 경계, 상수·준상수 채널, 결측 비율과 학습 구간의 라벨 오염 여부를
확인합니다. 이상 구간은 개수와 길이의 중앙값·최소·최대를 정리해 지우의 ℓ 검토와 주혜의
난이도 분석에 넘깁니다.

### 주기성

학습 구간만 사용해 채널별 자기상관의 국소 최대와 lag 상한을 제안합니다. 가능하면
다운샘플 배율에 따라 주기가 어떻게 달라지는지도 함께 정리합니다.

테스트 라벨 통계는 채점과 난이도 분석에만 씁니다. 모델 분할이나 정규화 기준은 학습 구간
통계로 정합니다. 결과는 시계열별 표로 정리하고 그림은 주기성에만 사용합니다.

완료 신호는 `manifest.md`의 검토와 보완이 끝난 상태입니다.
